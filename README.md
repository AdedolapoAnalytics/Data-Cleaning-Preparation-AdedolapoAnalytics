# Retail Sales Data Cleaning

## Project Overview

This project focuses on cleaning and preparing a retail sales dataset using Microsoft Excel.

The goal was to improve the quality and consistency of the raw dataset so that it could be used for further data analysis and visualization.

## Dataset

The dataset contains 1,000 retail sales orders and includes information about:

- Order details
- Customer information
- Products
- Quantity
- Unit price
- Payment methods
- Order status
- Coupon codes
- Referral sources

## Tool Used

- Microsoft Excel

## Data Cleaning Process

The dataset was cleaned and prepared by:

- Checking for missing values
- Checking for duplicate records
- Correcting data formats
- Formatting the Date column correctly
- Reviewing and cleaning inconsistent entries
- Validating Quantity and Unit Price values
- Creating additional fields needed for analysis
- Ensuring the dataset was properly structured for further analysis

## Outcome

The cleaned dataset was prepared for the next stage of the project, which involved exploratory data analysis and visualization.

## Project Purpose

This project demonstrates my ability to work with raw data in Microsoft Excel, identify data quality issues, and prepare datasets for analysis.
